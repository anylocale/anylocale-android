PlatformAnylocale

actual typealias PlatformAnylocale = AnylocaleAndroid(source)

Typealias representing a platform-specific implementation of the Anylocale class for Android.

This alias maps PlatformAnylocale to AnylocaleAndroid on the Android platform, allowing platform dependency abstraction in multi-platform projects. The actual implementation, AnylocaleAndroid, provides Android-specific utilities for managing translations and localization tasks using string resources.

An actual implementation of the Anylocale class for a specific platform. This class is used to handle platform-specific operations and configurations related to the Anylocale localization framework.
